## Global Superstore Sales Performance Analysis

### Project Overview
This project solves a common business problem in retail: understanding where a global company is making its money, which products and regions are driving growth, and where operational bottlenecks are slowing things down. By analyzing four years of company sales records (from 2011 to 2014) for Global Superstore, this project turns raw, messy transactional data into a clear, interactive two-page dashboard. This helps management see exactly which categories bring in the highest revenue, which regions perform best, and how shipping times impact operations so they can make smarter business decisions.
